
### Relational DataBase System  in LibreOffice Base
Designed and developed a complete Sales and Inventory Management System using LibreOffice Base to model real-world business transactions. 
Built a fully normalized 3rd Normal Form (3NF) relational database (TblCustomers, TblProducts, TblSales) with enforced referential integrity to eliminate data redundancy.
Leveraged custom SQL queries and built-in reporting tools to track stock levels, calculate order subtotals, and generate actionable business insights.
